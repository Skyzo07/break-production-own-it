One line, 1–200 characters: the brutally honest error message an AI agent
prints the instant it breaks production. `main.ts` writes it to
`/output/entry.txt`:

> Production is down because I 'fixed' a typo in the config. The typo was load-bearing.

Run locally with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
